# Task 1

Программа `options` обрабатывает опции практического задания 1 с помощью
`getopt(3C)`. Все опции сохраняются, а затем выполняются справа налево.
Повторение одной и той же опции поддерживается.

## Сборка

```sh
make
```

## Примеры

```sh
./options -i -p -d
./options -v -VTEST=hello | grep TEST
./options -U128 -u
./options -C1024 -c
./options -i-p
```

Опции:

- `-i` выводит реальные и эффективные UID/GID;
- `-s` делает процесс лидером группы;
- `-p` выводит PID, PPID и PGID;
- `-u` и `-Ulimit` читают и изменяют лимит открытых файлов;
- `-c` и `-Csize` читают и изменяют лимит размера core-файла;
- `-d` выводит текущую директорию;
- `-v` выводит окружение;
- `-Vname=value` добавляет или изменяет переменную окружения.

## Проверки ошибок

```sh
./options
./options -x
./options -Ubad
./options -VINVALID
```

Очистка результата сборки:

```sh
make clean
```
